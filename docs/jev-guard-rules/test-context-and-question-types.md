# Test context and question types

Part of [the Jev guard rules](../jev-guard-rules.md).

We used Jev to check a story game. Each turn, the player types a command and a narrator writes what happens. We asked two kinds of questions:

- **Fact questions** check one object at a time: "Did the phone move?"
- **Story-sense questions** check the whole turn: "Did the narrator start the scene over?"

Jev did well on the first kind and worse on the second.
