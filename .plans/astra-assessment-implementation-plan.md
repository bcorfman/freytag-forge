## Player-facing engine-error line (2026-10-14, Brandon's request; Ringer `astra-engine-error-line`)

`POST /api/v1/turn` now returns the fixed line `I don't understand. Can you try something else?` (`REJECTED_TURN_MESSAGE`, `validation.py`) as `detail` for engine errors: a rejected narration (409, `X-Freytag-Rejection-Code` kept), `RuntimeContractError` (422), `RuntimeStateError` (409) and any unexpected exception (500, traceback logged).
